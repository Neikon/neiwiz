# NeiWiz Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Plasma 6 system-tray plasmoid called NeiWiz that discovers WiZ bulbs and controls their power and brightness without any resident background service.

**Architecture:** The QML plasmoid keeps the bulb list and calls a short-lived Python helper through `Plasma5Support.DataSource` only when the panel opens or the user changes something. The helper uses `pywizlight` for discovery and local UDP control, prints JSON, and exits. Known IP/MAC pairs live in the applet configuration.

**Tech Stack:** Plasma 6 QML, `org.kde.plasma.plasma5support`, Python 3.11+, `pywizlight`, `pytest`, Bash installer.

**Spec:** `docs/superpowers/specs/2026-11-03-neiwiz-design.md`

## Global Constraints

- Applet name: `NeiWiz`; applet ID: `org.neikon.neiwiz`.
- Target: Plasma 6.7.5, Bazzite 44, Python 3.14 (fallback 3.13 via `uv`).
- No daemon, no systemd unit, no autostart, no listening port.
- User-level install only; no `sudo`.
- WiZ UDP port: `38899`; network: same LAN as the bulbs.
- UI copy in Spanish.
- Helper stdout: JSON only; logs go to stderr.
- Per-bulb timeout: 2 s; discovery wait: 2 s with a local-broadcast fallback.
- Helper path: `~/.local/share/neiwiz/wizhelper.py`; venv: `~/.local/share/neiwiz/venv`.
- Plasmoid ID in metadata and all commands: `org.neikon.neiwiz`.

## Review Focus

- An unreachable bulb must not block the panel or the other bulbs; it is marked `online: false` within the timeout.
- The first run on a network where `255.255.255.255` does not reach the bulbs must retry with the interface broadcast address.
- A missing helper must show an actionable install message, not an empty list.
- The QML executable runner must ignore partial `newData` events and parse only the final result with an exit code.
- Moving a brightness slider must not spawn a process per pixel; it commits on release.
- A DHCP address change must be recoverable by automatic or manual rediscovery.

### Task 3: Implement the helper CLI with tests first

**Files:**
- Modify: `helper/wizhelper.py`
- Modify: `tests/test_wizhelper.py`

**Interfaces:**
- Produces:
  - `async query_bulb(ip: str) -> dict` → `{"ip", "online", "on", "brightness", "mac", "error"?}`.
  - `async query_many(ips: list[str]) -> list[dict]`.
  - `async discover_bulbs(broadcast: str | None = None) -> list[dict]`.
  - `async set_bulb(ip: str, action: str, value: int | None = None) -> dict`.
  - `main(argv: list[str] | None = None) -> int`.
- JSON contract: `discover`/`state` → `{"ok": true, "bulbs": [...]}`; `set` → `{"ok": true, "ip": "..."}`; expected failures → `{"ok": false, "error": "..."}` on stdout, exit 0; unexpected exceptions → JSON error, exit 1.

- [ ] **Step 1: Write the failing CLI tests**

Add tests to `tests/test_wizhelper.py`:

- `test_query_many_marks_timeouts_offline`: monkeypatch `query_bulb` to raise `WizLightTimeOutError`; assert the result has `online: false` and an `error`.
- `test_discover_uses_global_then_local_broadcast`: monkeypatch `find_wizlights` to return `[]` for `255.255.255.255` and one fake bullet for `192.168.1.255`; monkeypatch `query_many`; assert both broadcast addresses were tried and one bulb is returned.
- `test_main_state_outputs_json`: monkeypatch `query_many`; call `main(["state", "--ip", "192.168.1.10"])`; parse stdout; assert `ok` and the bulb count.
- `test_main_set_brightness_maps_percent`: monkeypatch `set_bulb`; call `main(["set", "--ip", "192.168.1.10", "--brightness", "50"])`; assert it was called with `50`.
- `test_main_rejects_invalid_ip`: call `main(["set", "--ip", "not-an-ip", "--on"])`; assert JSON `ok: false`.
- `test_main_set_on_and_off_actions`: assert `--on` and `--off` call `set_bulb` with the matching action.
- `test_main_discover_with_no_bulbs`: monkeypatch `discover_bulbs` to return `[]`; assert `ok: true` and an empty list.

- [ ] **Step 2: Run tests and watch them fail**

Run: `.venv/bin/pytest tests/test_wizhelper.py -v`
Expected: FAIL on the new CLI tests because `query_many`, `discover_bulbs`, `set_bulb` and `main` are missing.

- [ ] **Step 3: Implement the async helper and CLI**

Use `pywizlight.wizlight`, `PilotBuilder`, `pywizlight.discovery.find_wizlights`, and the library exceptions. Set `pywizlight.bulb.TIMEOUT = 2.0` in a small comment-documented compatibility shim, wrap every operation in `asyncio.wait_for` with 2–2.5 s, and always `async_close()` the bulb in a `finally`. `discover_bulbs` uses `wait_time=2.0`, tries `255.255.255.255`, then `local_broadcast()` if the first pass finds nothing; it queries each discovered bulb and merges the state, keeping a bulb with `online: false` if its state query fails. `set_bulb` maps `brightness` through `percent_to_raw` and uses `turn_on(PilotBuilder(brightness=raw))`, `turn_off()` or `turn_on()`.

- [ ] **Step 2: Implement `ExecRunner.qml`**

Use a `QtObject` with a `Component` that creates a `Plasma5Support.DataSource` for each request. Set `engine: "executable"` before `connectedSources`, append a unique `# <id>` to the shell command, ignore `newData` until `data["exit code"]` is defined, call the callback once, and destroy the source. Include an 8-second watchdog timer that reports a timeout and destroys the source.

- [ ] **Step 3: Implement the state layer in `main.qml`**

Load `knownBulbs` from `Plasmoid.configuration` as JSON, expose a `ListModel` with roles `ip`, `mac`, `name`, `online`, `on`, `brightness`, `busy`, and implement:

- `refreshState()`: if the model is empty, call `discover()`; otherwise call `state --ip ...` for every known bulb in one helper invocation.
- `discover()`: call `discover`, replace the model, save `knownBulbs`, and handle the empty result.
- automatic rediscovery once per panel opening when every bulb is offline;
- `togglePower()` and `setBrightness()` with optimistic updates and revert on failure;
- `anyOn`/`onCount` recomputation after every model change;
- `Plasmoid.icon` (`flashlight-on-symbolic` / `flashlight-off-symbolic`), `Plasmoid.toolTipMainText`, `Plasmoid.toolTipSubText` and `Plasmoid.status`.

Call `refreshState()` from `Plasmoid.onExpandedChanged` when the panel opens; do not poll while closed.
